Add the `iiclab` theme (Ink In Caps site: lime on off-white) and `iiclab-dark` for its dark sections. Add a shared `--ds-font-family-display` token (Tailwind `font-display`), which equals `sans` by default. A theme may now override the shared font families: iiclab uses Anek Devanagari for body text and Deutschlander for display.
